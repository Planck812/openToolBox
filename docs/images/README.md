# README 配图

放在这里的图片会被各语言 README 首屏引用。

## demo.gif（最重要）

一段 8～15 秒的演示，是 README 转化率最高的元素。建议内容：

1. 在别的窗口（编辑器 / 浏览器）复制一段压缩的 JSON；
2. 按 `Alt+Space` 唤起 Open-Toolbox —— 展示"剪贴板自动读取 + 工具已推荐"；
3. 点进 JSON 查看器，格式化结果出现；
4. 回到首页，输入 `uuid` 或 `1699999999`，展示搜索即用；
5. 最后按 `Ctrl+Shift+S` 截个图收尾。

要点：**分辨率 1440×900 以内**、**文件 < 8 MB**（GitHub 对大图加载很慢）、去掉鼠标抖动的空白等待。

录制工具：ScreenToGif、LICEcap（Windows 免费）。

放好文件后，把四个 README 首屏里 `docs/images/demo.gif` 那行的 HTML 注释取消掉即可。
